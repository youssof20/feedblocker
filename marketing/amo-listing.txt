NAME
FeedBlocker

PREFERRED SLUG (subject to availability)
feedblocker

SUMMARY
Hide feeds, recommendations, Shorts and Reels on YouTube, Reddit, X, Facebook, Instagram and LinkedIn. Choose what to hide on each site. Open source, with no analytics.

DESCRIPTION
FeedBlocker lets you hide selected parts of six websites, with separate controls for each site and each element.

On YouTube, hide the home feed, sidebar recommendations, Shorts sections or end-screen cards. On Reddit, hide the Home, Popular and All feeds, sidebar suggestions and promoted posts. X, Facebook, Instagram and LinkedIn have their own feed and recommendation controls.

Open the popup on a supported site, enable FeedBlocker and choose what to hide. Changes apply without a Save button. Website access is requested when you first enable that site.

• Expand grouped controls to choose individual elements.
• Use “Show once” on supported hidden feeds to reveal them until navigation.
• Pause everywhere for 30 minutes or until tomorrow.
• Export and import settings as JSON.
• Use light or dark mode and keyboard-accessible controls.

The extension makes no external network requests and includes no analytics or telemetry. Preferences use Firefox's storage.sync and may sync through your Mozilla account if Firefox Sync is enabled. Source code is available under the MIT licence.

This is an initial public beta. Website layout changes can break hiding rules. X, Facebook, Instagram and LinkedIn controls are labelled Beta; all sites still need live-site verification. X does not have a “Show once” placeholder. Firefox for Android has not been tested. FeedBlocker does not block entire websites or change autoplay settings.

NOTES FOR REVIEWERS
Firefox MV3 extension. Desktop minimum: Firefox 140. Android manifest minimum: 142, but Android is untested and is not recommended for this initial listing.
Load the extension, open a supported site, then enable that site in the popup. Host permissions are optional and requested on first enable. Settings are stored with storage.sync. No analytics, telemetry, remote code or remote rule updates.
The runtime uses locally packaged JSON rules and CSS. Generated files are rules/*.css and content/site-data.js. Rebuild with node tools/build.js; run node tools/test.js and node tools/check.js. There is no minification or obfuscation. Source and generator are in the linked repository.
The report button opens a GitHub issue draft containing the current site URL and browser user agent; the user chooses whether to submit it. No issue is submitted automatically.
Live logged-in site verification is outstanding. Listing screenshots show the real popup with deterministic sample settings in a browser preview, not live-site tests.
